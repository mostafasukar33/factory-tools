# فلاش أون - الأدوات

- `index.html` الصفحة الرئيسية (لوجو + زرار لكل أداة)
- `accounts.html` الحسابات (العملا والموردين، كشف حساب PDF، مقفول بكلمة سر)
- `cash.html` دفتر الخزنة
- `delivery.html` إذن التسليم
- `quote.html` عروض الأسعار (PDF، أرشيف، نسخة احتياطية)
- `cost.html` حاسبة تكلفة كيلو الخرطوم
- `sw.js` يشتغل بالشبكة أولاً علشان دايماً يجيب آخر تحديث، ويفتح من الكاش لو مفيش نت

القواعد لإضافة أدوات جديدة في `CLAUDE.md`.
