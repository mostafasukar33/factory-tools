# اختبارات الحسابات ودفتر الخزنة وحركة السوق

```
node tests/run.js --changed     # العادي: بيختار لوحده من الملفات اللي اتغيرت عن origin/main
node tests/run.js               # كله (حوالي دقيقتين وربع)
node tests/run.js --only=mkt    # حركة السوق (حوالي دقيقة ونص) — زي MARKET_ONLY=1 القديم
node tests/run.js --only=acc    # كل حاجة ما عدا السوق (حوالي دقيقة)
node tests/run.js --only=smoke  # تعديل شكل بس: الصفحات بتفتح من غير أخطاء (حوالي 15 ثانية)
node tests/run.js --changed --dry   # يقول هيشغّل إيه بس
```

بيشغّل الموقع على الجهاز، ويفتحه في متصفح من غير شاشة، ويجرب بيانات تجريبية (مفيهاش أي عميل حقيقي):
كلمة السر والتشفير، نقل الإكسيل، الفواتير والدفعات والمرتجعات والخصم، الشيكات، الخزنة والجرد،
الربط مع دفتر الخزنة، كشف الحساب PDF، التقارير، قفل الفترة، المزامنة مع شيت Google على أكتر من جهاز، وقفل الشيتات بالمفتاح،
وتطبيق الشريك ووارد السوق.

كل اختبار بيقارن الأرقام بالقرش. لازم يطلع في الآخر "0 فشل" قبل رفع أي تعديل. في الآخر بيطبع وقت كل قسم.
`gasmock.js` بيقلّد Google Apps Script علشان نجرب كود الشيت من غير نت.

## إزاي `--changed` بيختار

| اللي اتغير | بيشغّل |
|---|---|
| `accounts.html` جوه الـ `<style>` بس (أو الـ head) | smoke |
| `accounts.html` جوه بلوك وارد السوق بس (آخر `<script>`) | mkt |
| أي حتة تانية في `accounts.html` | كله |
| `market.html` | mkt |
| `cash.html` | acc |
| `payroll.html` | `tests/payroll.js` |
| `lib/` أو `sw.js` أو `fonts/` أو ملفات الاختبار نفسها | كله |
| أي صفحة تانية (`index.html`، `quote.html`، ...) | smoke |
| ملفات كلام بس (`.md`) | ولا حاجة |

لو أكتر من نوع اتغير بيجمعهم (acc + mkt = كله).

## الانتظار الذكي (`settle`)

بدل "استنى 300 ملّي" بوقت ثابت، `X.settle(300)` بيستنى لحد ما كل الصفحات المفتوحة تخلص شغلها
(المؤقتات القصيرة، طلبات الشيت، التشفير، IndexedDB، تحميل الصور والسكربتات، الرجوع في التاريخ، حركة الأرقام)
وبعدها 60 ملّي هدوء. الرقم المكتوب هو **أقصى** انتظار، فعمره ما يبقى أبطأ من الأول.
ولو رجع بدري، ساعة كل الصفحات (`Date`) بتتقدم بالباقي مع بعض، فأي حاجة في البرنامج معتمدة على الوقت
(زي "دوستين في أقل من 700 ملّي = دوسة واحدة") بتشوف إن الوقت عدّى فعلاً.

- **متستخدمش `waitForTimeout`** في أي اختبار جديد. استخدم `settle` أو `waitForSelector`/`waitForFunction`.
- الأجهزة اللي خلص دورها بتتقفل (`close`) علشان مزامنتها في الخلفية متبطّأش الأقسام اللي بعدها.
- قبل الشغل ده الاختبار الكامل كان ~8 دقايق والسوق لوحده ~2 دقيقة.
